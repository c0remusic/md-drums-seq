MoDule Seq now runs on macOS as well as Windows: one zip holds the engine for both.

## New

- **macOS.** The device's engine, `mdseq.mxo`, is built for Intel and Apple Silicon, for macOS 11 or later, next to
  the Windows one. Max loads the one for its system. On a Mac, 0.2.0 opened an empty window: Max could not create its
  engine, which existed only for Windows. **The macOS engine is built by GitHub's runners and passes the same tests,
  but nobody has tried it on a Mac yet: reports are welcome.**

## Requirements and install

Windows 10 or 11 (64-bit), or macOS 11 or later; Live 12 with Max for Live; MoDule (or MD Drums) 0.1.0 or later, 0.1.1
or later for the Track names, 0.1.2 or later for the Accent and the Slide.

Unzip `MModuleSeq-0.2.1.zip` and put the `MoDule Seq` folder in Live's User Library under
`Presets/MIDI Effects/Max MIDI Effect/`, replacing 0.2.0's. Remove an older `md-drums-seq` folder (its engine has the
same name, and Max loads only one), and restart Live: Max never loads a new version of an engine it has already loaded.

**On macOS**, the engine is not notarized by Apple, so macOS refuses it as downloaded: the device's window stays empty
and Max's console says "mdseq: No such object". Once, in Terminal, take the download's mark off the folder (the path
is the User Library's default):

```
xattr -dr com.apple.quarantine ~/Music/Ableton/User\ Library/Presets/MIDI\ Effects/Max\ MIDI\ Effect/MoDule\ Seq
```
